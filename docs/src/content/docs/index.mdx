`oss` reads any repository through the GitHub API — no clone, any language — and
answers the questions a maintainer actually asks: is this pull request right,
has this been decided before, what is waiting on me.

**A GitHub token is the whole requirement.** Every download carries its own Java.
A local model and a notes folder each make it sharper, and neither is needed to
start.

## Two minutes to a first answer

```bash
brew install ramanathan1504/oss-cli/oss
export GITHUB_TOKEN=$(gh auth token)

oss sync --add apache/logging-log4j2   # register a project you follow
oss sync --all                         # pull it down; builds the index as it goes

oss critical                           # what arrived that matters most
oss search "rollover compression"      # have I seen this before
```

After that first sync, **29 of the 36 commands never touch the network again** —
including search by meaning, because the model doing the arithmetic runs inside
the process rather than behind an API.
